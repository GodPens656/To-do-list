# Облачные бэкапы

Для текущего авторизованного аккаунта приложение автоматически копирует
`groups.json`, `postponed.json`, `tasks.json` и `repeat_tasks.json` из его
папки на Яндекс Диске в:

```text
/For_to-do/<логин>_<пароль>/backups/backup_дд.мм.гггг/
```

Первый бэкап создаётся при запуске с сохранённым входом или после входа /
регистрации. Следующий — через 7 календарных дней после последнего полного
бэкапа. Фоновый поток проверяет срок раз в час, даже если дела не меняются.
Дата и наличие всех четырёх файлов проверяются в облаке, поэтому перезапуск
или вход с другого устройства не сбрасывают расписание.

Приложение должно работать и иметь доступ к интернету. Если оно было
закрыто, просроченный бэкап создаётся после следующего запуска с датой
фактического копирования. После сетевой ошибки попытка повторяется через
5 минут. Без авторизации бэкапы не создаются.

Копируются уже сохранённые в облаке файлы, с сохранением их текущего формата.
В «Настройки → Безопасность» можно отключить или повторно включить
шифрование данных текущего аккаунта. Настройка хранится в облаке и
учитывается при последующих выгрузках с других устройств. Изменение
применяется сразу при переключении и переводит существующие файлы дел
в облаке и на устройстве в выбранный формат. Настройка локального
хранения сохраняется после перезапуска. Для изменения нужны вход в аккаунт
и интернет. Старые бэкапы сохраняют прежний формат.
Сначала все четыре файла копируются во временную папку `.pending_*`,
затем она переименовывается в `backup_дд.мм.гггг`. Незавершённая копия
не считается успешным бэкапом. Старые бэкапы не перезаписываются и
автоматически не удаляются.

В «Настройки → Управление делами» кнопка «Отправить бэкап» создаёт копию
вручную, не чаще одного раза за календарный день на аккаунт. Если сегодня
уже есть полный бэкап (в том числе автоматический), повторная отправка
доступна на следующий день. Лимит проверяется по облачной истории и
сохраняется после перезапуска и на других устройствах. Ошибка отправки
не расходует лимит. После ручной копии следующий автоматический бэкап
создаётся через 7 дней. Во время отправки кнопка временно недоступна,
результат отображается под ней.

Проверка без обращения к настоящему облаку:

```powershell
python -m unittest discover -s tests -p 'test_cloud*.py'
```
